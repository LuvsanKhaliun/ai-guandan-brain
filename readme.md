# 掼蛋（GuanDan）AI 大脑

暑期实践课程项目：一个能够自动登录、加入牌桌并与其他玩家 / 基线 bot 对战的掼蛋 AI。

## 一、运行环境 / 依赖

- **语言**：Python 3.8 及以上（开发时使用 Python 3.14，未使用任何新版本专属语法，理论上 3.8+ 均可运行）
- **第三方依赖**：仅需 `requests`

安装依赖：

```bash
pip install requests
```

其余模块（`json`、`time`、`itertools`、`collections` 等）均为 Python 标准库，无需额外安装。

## 二、项目结构

```
.
├── step09.py        # 主程序：登录 / 加入牌桌 / 消息循环 / 出牌通信
├── strategy.py       # 出牌策略：主动出牌与被动接牌的决策逻辑
├── recognizer.py      # 牌型识别（含红桃级牌“逢人配”处理）
├── generator.py       # 合法出牌枚举
├── comparator.py      # 牌型大小比较
├── card_tracker.py     # 记牌模块：根据出牌记录推算未出现的牌
└── README.md         # 本说明文件
```

各模块的具体设计思路见随附的《实验报告》PDF。

## 三、运行前需要修改的内容

打开 `step09.py`，将文件顶部的账号信息替换为你自己的：

```python
USER = "你的学号"
PASSWORD = "你的加密后密码"
```

> `PASSWORD` 需要是按课程第 5 步（RSA 加密登录）要求，用课程给定的公钥（`e`, `n`）对明文密码加密后的十六进制字符串，而不是明文密码本身。如果你还没有完成加密登录的验证步骤，请先参照课程第 5 步的说明生成该字符串。

如需连接到不同的服务器地址，修改同文件中的：

```python
BASE = "http://183.175.14.145:8006"
```

## 四、如何运行

在项目根目录下直接运行主程序：

```bash
python step09.py
```

程序会依次完成：

1. 请求首页，确认服务是否可访问；
2. 调用 `/join_game/` 登录并加入一桌（默认会自动匹配 3 个基线 bot，立即开局）；
3. 进入消息循环：
   - 调用 `/check_game/{game_id}/` 查询当前牌局状态；
   - 若 `completed` 为真，打印终局信息并结束程序；
   - 若轮到自己（`is_your_turn` 为真），调用 `strategy.py` 中的 `choose_move()` 计算出牌，
     再调用 `/play_game/{game_id}/` 提交；
   - 否则等待 5 秒后重新查询；
4. 循环直到牌局结束，终端会打印详细的调试信息（当前手牌、场上最后一手牌、AI 的出牌选择等），
   便于观察 AI 的决策过程。

程序运行期间会持续打印每一轮的状态，属于正常现象，无需人工干预；若中途想提前终止，
直接按 `Ctrl+C` 即可，不会影响服务器端的牌局数据，重新运行 `python step09.py` 会自动加入一局新的牌桌。

## 五、如何与真人玩家对战

`join_game()` 默认不传 `humans` 参数，会自动配 3 个基线 bot 开局。若想尝试匹配真人玩家，
在 `step09.py` 的 `join_game()` 函数中，将请求参数改为：

```python
payload = {
    "user": USER,
    "password": PASSWORD,
    "humans": 1
}
```

其余流程不变，程序会按同样的消息循环自动完成整局对战。

## 六、常见问题

- **报错 `is_success: false` 且提示找不到用户 / 密码错误**：请检查 `USER` / `PASSWORD` 是否正确，
  以及密码是否是加密后的十六进制字符串而非明文。
- **报错 `cannot beat the table`**：属于策略层的出牌判断问题，不影响程序运行，
  程序会在下一轮根据最新的场上信息重新计算出牌，具体原因分析见《实验报告》第五节。
- **想调整 AI 的保守 / 激进程度**：可以修改 `strategy.py` 顶部的两个阈值
  `DANGER_HAND_SIZE`（对手还剩几张牌时值得主动用炸弹拦截）与
  `TEAMMATE_DANGER_SIZE`（队友还剩几张牌时应更谨慎地保住出牌权），默认均为 2。
